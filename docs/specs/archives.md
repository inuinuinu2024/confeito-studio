# ARCHIVES（作業データの保存と一覧）

## 保存形式
- 1 アーカイブ = `archives/` 直下の 1 フォルダ。中のファイル・サブフォルダはそのまま保存される（ZIP 形式は廃止）。
- 既存アーカイブへのファイル追加・上書きができる。名前に `..` `/` `\` を含むアーカイブ名、アーカイブ外を指すパスは拒否する。
- フロントエンドはエントリを `"<アーカイブ名>/<相対パス>"` のキーで扱う。
- ツールは作業ログ（log.txt）・エラー記録（error.txt）を書かない（[notifications.md](./notifications.md)「ログ」）。
  以前のバージョンが書いたものは残り、テキストファイルとして表示される。

## ツールの結果の保存
全ツール共通のルール（バックエンド `archive_service.save_result`、フロント `features/tools/result.ts` の `saveToolResult`）。

- **保存先**: 選択中のアーカイブ（保存先フォルダのトップレベル）の中に `<YYYYMMDD_HHMMSS>_<ツール名>/` を作り、結果をまとめて入れる。
  サブフォルダやその中のファイルを選んでいても、作るのはトップレベルの直下。何も選択されていなければ新しいアーカイブ `<YYYYMMDD_HHMMSS>_<ツール名>` を作る。
  - 例外: 画像読み込みは毎回新しいアーカイブ `<YYYYMMDD_HHMMSS>_<画像名>`（取り込んだ画像だけを入れる）。
- **名前**: ツール名は表示名（`コマ分割`, `コマ結合`, `背景除去`, `Nano Banana画像生成`）。同じ名前のフォルダ・アーカイブがあれば
  `_2`, `_3` … を付けて、既存のものを上書きしない。
- **info.json**: 結果フォルダに 1 つ置く（画像読み込みのアーカイブには置かない）。
  ```json
  {
    "tool": "背景除去",
    "created_at": "2026-10-02 20:03:00",
    "source": "20261002_200000_page/page.png",
    "settings": { "alpha_matting": true, "fg_threshold": 240, "bg_threshold": 10, "erode_size": 10 },
    "outputs": ["nobg.png"]
  }
  ```
  - `source`: 入力の ARCHIVES キー（キャンバスに表示中の画像。コマ結合は対象フォルダ）。Nano Banana画像生成 は null（入力は Inputs/ の参照画像）。ただしキャンバスの画像を原画にした時はその画像のキー。
  - `settings`: そのツールの設定値。`outputs`: info.json 以外に保存したファイル（結果フォルダからの相対パス）。
- **入力のコピーは残さない**（元画像はアーカイブにあるため）。Nano Banana画像生成 の参照画像（`Inputs/`）は、アーカイブ外から追加したものもあるので残す。原画も、ファイルから設定した時だけ `Inputs/Original.*` に残す。
- **保存後**: 結果の画像（コマ分割は `01.png`）を自動で選択してキャンバスに表示する。表示した画像のアーカイブが次の保存先になる。

| ツール | 結果フォルダの中身 |
|---|---|
| コマ分割 | `01.png`, `02.png`, …, `panels.json`, `info.json` |
| コマ結合 | `<YYYYMMDD_HHMMSS>_コマ結合.png`, `info.json` |
| 背景除去 | `nobg.png`, `info.json` |
| Nano Banana画像生成 | `<YYYYMMDD_HHMMSS>_Nano Banana画像生成.png|.jpg`, `Inputs/Image1.*` …, `Inputs/payload.json`, `info.json`（原画がある時は `Raw/generated.*`、ファイルから設定した原画の `Inputs/Original.*` も） |

## 一覧（ツリー）
- 起動時はトップレベルのアーカイブを新しい順に折りたたんで表示し、展開した時に中身を取得する（遅延読み込み）。
- サブフォルダ（コマ分割で作られるもの等）も独立して展開・折りたたみできる（chevron クリックまたは行のダブルクリック）。
  折りたたまれたフォルダの中身は表示しない。展開状態は左右のパネルで共有し、アプリ起動ごとにリセットする。
- 展開・折りたたみの操作をしても選択は維持する。折りたたみで見えなくなった項目だけ選択から外し、選択が変わった時は
  キャンバスもそれに合わせる（表示中の画像が隠れればキャンバスは空になる）。
- 拡張子のないファイルは「.png」を付けて表示する。json / txt / md はテキストアイコンで表示する。
- 更新ボタン: 中身のキャッシュを捨ててバックエンドから再取得する。更新前の選択のうちまだ存在するものは選択を維持して表示し直し
  （ファイルの中身の変化を反映）、消えたものは選択から外す（全部消えればキャンバスは空）。実行中はアイコンが回転し、完了時にトーストを出す。
- ツリーを読み直す時（展開・折りたたみ・更新・`archives:changed`）は、選択を行の位置ではなくキーで覚え直す。
- ツールの実行後などで `archives:changed` に `autoSelectKey` が付いている場合、その親フォルダを展開して選択し、表示する。

## 選択
- クリックで単一選択、もう一度クリックで選択解除。Ctrl/⌘ で追加・解除、Shift で範囲選択。
- 選択したフォルダの配下に表示されている行は選択色で表示する。
- ファイルを 1 つ選択するとキャンバスに表示する（テキストファイルは文字表示）。選択解除でキャンバスは空になる。
  フォルダの選択・複数選択では Normal モードのキャンバスに画像を出さず、案内文で選択内容を示す（canvas.md「表示ルール」）。
- **保存先フォルダ**（`DocumentManager.getCurrentArchiveFolder()`）: 左の ARCHIVES で選んでいる場所（Parallel モードの右の ARCHIVES での選択では変わらない）。ツールはそのトップレベルのアーカイブに
  結果を保存し（上の「ツールの結果の保存」）、コマ結合はここからコマを読む。
  - ファイル（画像・テキスト）を選択 → その親フォルダ（サブフォルダの中なら `root/sub`、直下ならアーカイブ）。
    ツールはそのトップレベルに保存するので保存先は変わらず、コマ結合はコマ分割フォルダの画像を選んでいてもそのフォルダを対象にする。
  - フォルダ行を選択 → そのフォルダのキー（サブフォルダなら `root/sub`）。
  - 複数選択 → 最初に選んだファイルの親フォルダ（フォルダだけを選んでいる時は最初に選んだフォルダ）。
  - 選択を解除 → なし（前に選んだ場所へ保存されることはない）。
- Batch モードでは選択をグリッドで表示する（フォルダ → 配下の全画像、ファイル → 選んだ画像だけをツリー順に。詳細は canvas.md）。

## 削除と Undo
- 削除ボタンで選択中の項目をゴミ箱（`archives/.trash/`）へ移す（Parallel モード中は無効）。完全には消さない。
  - トップレベルのアーカイブ → `.trash/<アーカイブ名>/`。
  - アーカイブ内のファイル・サブフォルダ → `.trash/.items/<アーカイブ名>/<元の相対パス>`。空になったフォルダは消し、
    アーカイブ自体が空になったらアーカイブのフォルダも消す（中身はゴミ箱にある）。
  - フォルダとその中のファイルを同時に選んだ場合は、フォルダごと 1 回だけ移す。
  - ゴミ箱に同じ場所の古いものがあれば上書きする。
  - 削除後は更新ボタンと同じくツリーを自動で再取得し、削除した項目を表示から消す（選択は解除、キャンバスは空になる）。
- ゴミ箱はアプリ起動時（バックエンド起動時）に中身をすべて完全に削除する。消せなかったもの（他のアプリが開いている等）は残し、
  バックエンドのログに警告を出す。このため削除の取り消しは同じ起動中だけ。
- Ctrl+Z で直前の削除を取り消すと、ゴミ箱から元の場所へ戻す（アーカイブ・ファイル・サブフォルダとも）。
  空になって消えたアーカイブも作り直す。戻す先に同名のファイルができていれば、ゴミ箱の内容で置き換える。
  戻せなかった場合は「削除を元に戻せませんでした」と表示する。Ctrl+Y でやり直せる。
- `.` で始まる名前はゴミ箱用に予約しており、アーカイブ名に使えない。

# AI パネル（ツール一覧と実行）

## タブ
- ヘッダーに「Custom」（左）と「All Tools」（右）のタブ。アイコンは付けず、テキストと件数バッジのみ。
- **All Tools**: 登録された全ツール（`features/tools/index.ts` の順が初期順）。ドラッグで並び替えでき、
  右端のピンで Custom への追加・解除を切り替える。
- **Custom**: ピン留めしたツールだけを表示。独立して並び替えでき、× で外せる。0 件の時は案内文を表示する。
  初回起動時は Nano Banana Pro がピン留めされている。
- 次の状態は localStorage に保存し、再起動後も復元する:
  `aiPanelActiveTab`（選択中のタブ）、`toolOrder`（All Tools の並び）、`customToolOrder`（Custom の組み合わせと並び）。

## ツールの実行
- ツールを押すと、`canOpen()` で実行条件を確認する（満たさない場合はトーストで理由を出して終わる）。
- 設定のあるツールは右から設定サイドバー（幅 360px）を開き、下部の実行ボタンで実行する。成功するとサイドバーを閉じる。
  外側をクリックしても閉じない（× で閉じる）。設定のないツールは押した時点で実行する。
- 実行中はステータスバーに進行状況を出す。成功時は「<ツール名> completed.」、失敗時は「<ツール名> failed: <理由>」のトースト。
- 失敗時のエラー記録（ツール自身が記録済みの場合を除く）:
  - 保存先フォルダがあれば、そのアーカイブの `error.txt` に `[YYYYMMDD_HHMMSS] (<ツール名>): <理由>` を追記。
  - なければ新しいアーカイブ `YYYYMMDD_HHMMSS_<ツール名>_error/error.txt` を作る。
- ファイル選択のキャンセルなどはエラー扱いしない。

## ツール設定の保存
- 各ツールの設定値は `settings/default_prompts.json`（フラットな文字列マップ）に即時保存し、起動時に読み込む。
- キーはツールごとの接頭辞付き: `nanoBananaPro_*`、`panelSplitter_*`、`removeBg_*`。
  削除したツールのキー（`coloring_*` など）はファイルに残っていても使われない（ファイルからは消さない）。
- 共通の UI: JSON プレビュー（送信内容の確認とコピー）、ヘルプアイコン（ツールチップ）、プロンプト欄の鉛筆アイコン（デフォルトプロンプトの編集）。

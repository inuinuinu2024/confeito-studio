# AI パネル（ツール一覧と実行）

## ツール一覧
- ヘッダーは見出し「TOOLS」のみ（ARCHIVES パネルのヘッダーと同じ見た目）。タブ・Custom（お気に入り）・ピン留めは持たない。
- 登録された全ツールを 1 列に並べる（`features/tools/index.ts` の順が初期順）。ドラッグで並び替えできる。
- 並び順はユーザー設定（`settings/user_settings.json`）のキー `aiPanel_toolOrder`（ツール名の JSON 配列）に並べ替えた時点で保存し、再起動後も復元する。
  ブラウザには保存しない（[app-shell.md](./app-shell.md)「ブラウザに残すもの」）。以前のバージョンが localStorage に保存した
  `toolOrder`・`aiPanelActiveTab`・`customToolOrder` は読まない（引き継がないので、初回は初期順に戻る）。

## ツールの実行
- 設定のあるツールは**ツールウィンドウ**（アプリ内のモーダル。`features/ai-panel/components/ToolWindow.ts`）を開き、下部の実行ボタンで実行する。
  画像読み込みだけはウィンドウを開かず、押した時点で実行する（ファイル選択が開く）。コマ結合は設定項目がないが、対象フォルダの確認のためにウィンドウを開く。
- ツールウィンドウ:
  - 画面の中央に出す。開いている間は背景を暗くし、ほかの操作（ARCHIVES・キャンバス・メニュー）はできない。
  - 大きさは固定（動かせない・変えられない）。幅は 480px（画面が狭ければ画面幅 − 32px）、高さは中身に合わせ、
    最大は画面の高さ − 上下 48px。超える分は本文だけスクロールし、見出し（アイコン・ツール名・×）と実行ボタンは常に見える。
  - 項目の多いツールは横に広げて複数列にできる（`Tool.windowColumns`。1 列 400px、列ごとにスクロール。幅 960px 以下の画面では縦に並べる）。
    今は Nano Banana画像生成 だけが 3 列（1200px）。
  - 1 枚だけ。閉じ方は × ボタン、Esc キー、背景（暗い部分）のクリック。
    背景クリックは押した場所と離した場所の両方が背景の時だけ閉じる（スライダー操作で外へはみ出しても閉じない）。
    Esc は、上に JSON プレビューやプロンプト編集のダイアログが開いている時はそちらだけを閉じる。設定は変更した時点で保存済み。
  - 実行ボタンの文言は全ツール共通で「実行」（アイコンはツールごと）。
  - 実行中は実行ボタンを無効にし「実行中…」と表示する。成功したら閉じ、実行条件の不足や失敗では開いたままにする。
  - 閉じると、押したツールのボタンにフォーカスを戻す。
- 実行中はステータスバーに進行状況を出す。
- 結果はトーストで 1 回だけ知らせる（成功・実行条件の不足・失敗の出し分けは [notifications.md](./notifications.md)「ツール実行時」）。
  トーストはツールウィンドウの上に表示する。画像未選択などの実行条件は実行ボタンを押した時に確認し、不足なら注意トーストを出す
  （ウィンドウは開いたまま。選び直すには一度閉じて ARCHIVES で選ぶ）。
- ログ（log.txt / error.txt）は書かない。ファイル選択のキャンセルなどは何も出さない。

## ツール設定の保存
- 各ツールの設定値は、ツールウィンドウを開く時に読み込み、ツールの実行を始めた時に保存する
  （初期設定 `settings/default_prompts.json` とユーザー設定 `settings/user_settings.json`。詳細は [app-shell.md](./app-shell.md)「設定の保存」）。
- キーはツールごとの接頭辞付き: `nanoBananaPro_*`、`panelSplitter_*`、`removeBg_*`（ツールの `settingsPrefix`）。
  削除したツールのキーは初期設定から消す（以前の着彩ツールの `coloring_*` は削除済み）。
- 共通の UI: JSON プレビュー（送信内容の確認とコピー）、ヘルプアイコン（ツールチップ）、プロンプト欄の鉛筆アイコン（デフォルトプロンプトの編集）。

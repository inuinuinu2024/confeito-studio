# Prompt Manager と登録プロンプト

ユーザーが登録したプロンプトを、全ツールで共有する 1 つの一覧として管理する。
管理は Prompt Manager（左端の表示モード）で行い、ツール（今は Nano Banana画像生成）からは登録と呼び出しだけを行う
（ツール側の操作は [tools/gemini-image.md](./tools/gemini-image.md)「プロンプト」）。

## データ
- 1 件 = **名前・カテゴリー・本文**（＋自動の id）。ツールごとに分けず、全ツールで同じ一覧を使う。
- **名前**: 前後の空白を除いて 1〜100 文字。**全体で一意**（カテゴリーが違っても同じ名前は使えない）。大文字・小文字、全角・半角は区別する。
- **カテゴリー**: 自由入力（入力欄に既存のカテゴリーが候補として出る）。前後の空白を除いて 0〜50 文字。
  - 任意。空なら「未分類」として扱う。「未分類」と入力しても空と同じ。
  - カテゴリーを作る・消す操作はない。プロンプトに付けた名前がカテゴリーになり、使われなくなったカテゴリーは一覧から消える。
- **本文**: 空（空白だけ）にできない。前後の空白もそのまま保存する。
- **並び順**: プロンプトもカテゴリーも手動で並べ替える（下の「並べ替え」）。新しいもの（新規・登録・インポート・カテゴリー変更で移ったもの）は末尾に入る。
  「すべて」は先頭、「未分類」は常に最後。

### 保存先
- `assets/prompts/prompts.json`（git 管理外・ユーザーデータ。`CONFEITO_ASSETS_DIR` で `assets/` の場所を変えられる）。
  `assets/prompts/` はバックエンドの起動時に作る（なければ）。
  ```json
  {
    "categories": ["着彩", "背景"],
    "prompts": [{ "id": "<自動>", "name": "着彩（線画維持）", "category": "着彩", "text": "..." }]
  }
  ```
  - `categories` はカテゴリーの並び順（「未分類」は含めない）、`prompts` は全体の並び順（カテゴリーの中の順はこの順）。
  - アプリが書く時は、カテゴリーの順にプロンプトを並べ直し、使われていないカテゴリーを除いて書く。
- 変更（作成・編集・削除・複製・並べ替え・カテゴリー名の変更・インポート）はその場で保存する。一時ファイルに書いてから置き換える。
- **アプリの外での編集**: Prompt Manager を開く時・ツールの一覧を開く時・変更する時に毎回ファイルから読み直すので、外で直した内容も反映される。
  - `categories` にないカテゴリーは、最初に出てきた順に末尾へ足す。
  - 形の正しくない項目（id・名前・本文が文字列でない）は読み飛ばす（次に書く時に消える）。
    名前が重複していても読み込む（編集で別の名前にするまでそのまま）。
- JSON として読めない時: 上書きせずに `prompts.broken-<YYYYMMDD_HHMMSS>.json` へ退避し、空の一覧で読み込む。
  注意トースト「プロンプトファイル（prompts.json）が壊れていたため <退避先> に退避し、登録プロンプトなしで読み込みました。」
- 以前の保存先 `settings/prompts.json`（ツールごとの一覧）は読まない・移さない・消さない。

## Prompt Manager（`features/prompt-manager/`）
- 左端の列のマネージャーのグループにある「Prompt Manager」（chat アイコン）で開く。**表示モードの 1 つ**（Normal / Batch / Parallel / Overlay / Character Manager と排他）。
  - もう一度押すと Normal に戻る。ほかのモードのボタンを押すとそのモードに切り替わる。開いている間はアイコンを選択中の色にする。
  - 開くたびにファイルから読み直す（カテゴリーの選択は「すべて」、検索は空、編集欄は空に戻る）。
- 画面:
  - ARCHIVES の場所（左サイドバー）にカテゴリー一覧。
  - キャンバスの場所に、プロンプト一覧（左）と編集欄（右）。
  - 右サイドバー（AI パネル）は閉じる（ツールは実行しない）。
  ```
  ┌PROMPTS ⟳ ⇪ ⇩─┬[検索______][+ 新規]┬ 名前 [            ]      ┐
  │ すべて    12 │ ■ 着彩             │ カテゴリー [      ]       │
  │ 着彩       5 │ ⋮⋮ 着彩（線画維持）│ 本文                      │
  │ 背景       4 │ ⋮⋮ ベタ塗り        │ ┌───────────────────────┐ │
  │ 未分類     3 │ ■ 背景             │ │                       │ │
  │              │ ⋮⋮ 夕焼けの空      │ └───────────────────────┘ │
  │              │                    │       [削除][複製][保存] │
  └──────────────┴────────────────────┴───────────────────────────┘
  ```

### カテゴリー一覧（左サイドバー）
- 見出し「PROMPTS」と右のボタン: 再読み込み（ファイルから読み直す）・インポート・エクスポート。左サイドバーの幅は ARCHIVES と共通（端のドラッグで変更）。
- 行: 「すべて」（全件数）、カテゴリー（件数）、「未分類」（未分類が 1 件以上ある時だけ）。クリックでプロンプト一覧を絞り込む。
- **名前の変更**: カテゴリーの行をダブルクリック（または行の鉛筆アイコン）でその場で入力。Enter / 入力欄から離れると確定、Esc で取り消し。
  - そのカテゴリーの全プロンプトのカテゴリーをまとめて変える。カテゴリーの順の位置はそのまま。
  - 既存の別のカテゴリー名にすると、確認「「<旧>」のプロンプト N 件を「<新>」にまとめますか？」→「まとめる」で統合する（統合先の末尾へ移る）。
  - 空にすると、確認「「<旧>」のプロンプト N 件を「未分類」に移しますか？」→「移す」で未分類へ（末尾へ移る）。
  - 「すべて」「未分類」は名前を変えられない。
- **並べ替え**: カテゴリーの行をドラッグ（「すべて」「未分類」は動かない）。
- **プロンプトの移動**: プロンプト一覧の行をカテゴリーの行（「未分類」を含む）へドラッグすると、そのカテゴリーの末尾へ移る（その場で保存）。
  「すべて」へは落とせない。編集中のプロンプトなら、編集欄のカテゴリーも変わる（ほかの未保存の変更はそのまま）。

### プロンプト一覧
- 上に検索欄と「+ 新規」。検索は名前と本文に含まれる文字（大文字・小文字を区別しない）で、選んでいるカテゴリーの中を絞り込む。
- 「すべて」を選んでいる時はカテゴリーごとの見出しを付けて並べる（カテゴリーの順、未分類は最後）。カテゴリーを選んでいる時は見出しなし。
- 行は名前だけ（全文はツールチップ）。クリックで編集欄に開く。編集欄で開いている行は選択中の色。
- 0 件の時: 登録が 0 件なら「登録されたプロンプトはありません。「+ 新規」から作成できます。」、検索・絞り込みで 0 件なら「条件に合うプロンプトはありません。」
- **並べ替え**: カテゴリーを 1 つ（「未分類」を含む）選んでいて、検索欄が空の時だけ、行のつまみ（⋮⋮）をドラッグして並べ替えられる（その場で保存）。
  行のどこをつかんでもよい（つまみは並べ替えられることの目印）。「すべて」や検索中はつまみを出さない（カテゴリーへの移動はできる）。

### 編集欄
- 何も開いていない時は「プロンプトを選ぶか「+ 新規」で作成してください。」
- 項目: 名前・カテゴリー（候補付きの自由入力。空欄の表示は「未分類」）・本文。ボタン: 削除・複製・保存。変更があると見出しに「未保存」を出す。
- **保存**: 「保存」または Ctrl+S（Prompt Manager 中は入力欄の中でも効く。ダイアログが開いている間は効かない）。
  - 名前が空・100 文字超、本文が空、ほかのプロンプトと同じ名前の時は注意トーストを出して保存しない。
  - カテゴリーを変えて保存したプロンプトは、新しいカテゴリーの末尾へ移る。同じカテゴリーなら位置はそのまま。
  - 保存したプロンプトが今の絞り込みで見えなくなる時は、そのカテゴリーに切り替える（検索は空にする）。
  - トースト「プロンプト「<名前>」を保存しました」。
- **+ 新規**: 編集欄を空にする。カテゴリーは左で選んでいるもの（「すべて」「未分類」なら空）。「保存」を押すまで一覧に入らない。
  新規の時は削除・複製ボタンの代わりに「破棄」で編集欄を閉じる。保存するとそのカテゴリーの末尾に入る。トースト「プロンプト「<名前>」を作成しました」。
- **複製**: 保存済みの内容を「<名前> のコピー」（あれば「<名前> のコピー (2)」…）として元の直後に作り、複製を編集欄に開く。
- **削除**: 確認「「<名前>」を削除しますか？」→「削除」。元に戻す機能はない。
- **未保存の変更がある時**に、別のプロンプトを開く・「+ 新規」・複製・Prompt Manager を閉じる（ほかのモードへ切り替える）と、
  確認「「<名前>」の変更が保存されていません。」→「保存」「破棄」「キャンセル」。保存に失敗した時は切り替えない。
  カテゴリーの絞り込み・検索・再読み込みは編集欄に影響しない。
- 開いているプロンプトがほかのタブ・アプリの外で消されていた時（保存時）: エラートースト「プロンプトが見つかりません（削除された可能性があります）。」

### エクスポート / インポート
- **エクスポート**: 全件（カテゴリーの順を含む）を JSON ファイルとしてブラウザのダウンロードで保存する。ファイル名 `confeito-prompts-<YYYYMMDD_HHMMSS>.json`。
  ```json
  { "format": "confeito-prompts", "version": 1, "categories": ["着彩"], "prompts": [{ "name": "...", "category": "着彩", "text": "..." }] }
  ```
- **インポート**: ファイル選択（.json）。`prompts` の配列を持つ JSON を読む（エクスポートしたファイル・`prompts.json` のどちらも読める）。
  - 今の一覧に追加する（末尾へ。新しいカテゴリーはファイルの順で末尾に足す）。
  - 同じ名前のプロンプト（登録済み、またはファイルの中で先に出たもの）がある時は、まとめて 1 回だけ確認する:
    「N 件の名前がすでに登録されています。」→「上書き」「名前を変えて追加」「スキップ」「キャンセル」。
    - 上書き: カテゴリーと本文を置き換える（カテゴリーが変わったら新しいカテゴリーの末尾へ）。
    - 名前を変えて追加: 「<名前> (2)」「<名前> (3)」…の空いている名前で追加する。
  - 名前・本文が正しくない項目は読み込まず、件数を注意トーストで知らせる。
  - トースト「プロンプトを読み込みました（追加 N 件・上書き N 件・スキップ N 件）」。JSON として読めない・`prompts` がない時はエラートースト。
- エクスポート・インポートは、編集欄の未保存の変更には触れない（インポート後も編集欄はそのまま）。

## API（`/api/prompts`）
| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/prompts` | `{categories, prompts, warnings}`（カテゴリーの順・表示順のプロンプト） |
| POST | `/api/prompts` | `{name, category, text}` を末尾に作成 → `{prompt, warnings}` |
| PUT | `/api/prompts/{id}` | 名前・カテゴリー・本文を置き換え → `{prompt, warnings}` |
| DELETE | `/api/prompts/{id}` | 削除 → `{warnings}` |
| POST | `/api/prompts/{id}/duplicate` | 元の直後に複製 → `{prompt, warnings}` |
| PUT | `/api/prompts/{id}/category` | `{category}` に移す（末尾へ）→ `{prompt, warnings}` |
| PUT | `/api/prompts/order` | `{category, ids}` そのカテゴリーの中の順 → `{warnings}` |
| PUT | `/api/prompts/categories/order` | `{categories}` カテゴリーの順 → `{warnings}` |
| POST | `/api/prompts/categories/rename` | `{old, new}` 名前の変更・統合 → `{warnings}` |
| POST | `/api/prompts/import` | `{prompts: [{name, category, text}], categories, on_conflict: overwrite / rename / skip}` → `{added, overwritten, skipped, invalid, warnings}` |

- 並べ替えで送った id の組がファイルの今の内容と合わない時（ほかのタブで変わった時）は 409「プロンプトの一覧が変わっています。読み直してから並べ替えてください。」

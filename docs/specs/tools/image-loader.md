# 画像読み込み（`features/tools/image-loader.ts`）

- AI パネルのツール。押すとツールウィンドウが開き、「実行」（アイコン: フォルダを開く）でファイル選択のダイアログが開く。
  ▶ ボタンで実行した場合は、ウィンドウを開かずにそのままダイアログが開く（[ai-panel.md](../ai-panel.md)「ツール一覧」）。
- ウィンドウの設定項目は「最初に開くフォルダ」（テキスト欄、キー `imageLoader_initialDir`、初期値は空欄）だけ。
  - ダイアログを最初に開くフォルダを絶対パスで書く（例: `D:\manga\raw`）。前後の空白と、エクスプローラーの「パスのコピー」で付く `"` は無視する。
  - 空欄ならダイアログはこのアプリのプロジェクトのフォルダ（リポジトリの直下。`frontend/`・`backend/`・`archives/` などがある場所）で開く。
  - 存在しないフォルダや相対パスは実行条件の不足として扱い、注意トースト（「フォルダが見つかりません: <パス>」
    「フォルダは絶対パスで指定してください: <パス>」）を出してダイアログを開かない（ウィンドウは開いたまま）。
  - 設定は実行を始めた時に保存する（ほかのツールと同じ。[app-shell.md](../app-shell.md)「設定の保存」）。
- ファイル選択のダイアログ:
  - ブラウザのファイル選択は任意のフォルダから開けないため、バックエンドが OS のダイアログ（tkinter）を開く
    （`POST /api/local-files/pick-image`）。ダイアログはバックエンドを動かしている PC に、ほかのウィンドウより手前に出る。
  - 1 枚だけ選べる。種類の絞り込みは画像（PNG / JPEG / WebP / BMP / GIF）。画像以外を選んだ場合はエラートースト
    「画像ファイルではありません: <ファイル名>」。
  - キャンセル時は何もしない（トーストなし）。
  - 同時に開けるダイアログは 1 つ。開いている間にもう一度開こうとするとエラートースト（「ファイル選択のダイアログがすでに開いています。…」）。
    停止（⏸）してもダイアログは閉じられず、そこで選んだ画像は読み込まない（[ai-panel.md](../ai-panel.md)「実行の停止」）。
- Workspace への画像のドラッグ＆ドロップも同じ読み込み処理を行う（ダイアログは開かない）。Workspace で何を選んでいても選択は使わない。
- 処理内容:
  1. アーカイブ `YYYYMMDD_HHMMSS_<画像名>` を作る（画像名は拡張子を除いたベース名で、`\ / : * ? " < > |` を `_` に置換）。
     同じ名前があれば `_2`, `_3` … を付ける。表示名は `<画像名>`（同じ表示名があれば「<画像名> (2)」…。[archives.md](../archives.md)「表示名」）。
  2. 元画像を同じファイル名でコピーする（log.txt・info.json は置かない。表示名の `.archive.json` だけを置く。[archives.md](../archives.md)「ツールの結果の保存」）。
  3. Workspace でそのアーカイブを表示し（次の結果の保存先になる）、取り込んだ画像（開始画像）を選択する。
- 完了・失敗の通知はツール実行の共通ルール（[notifications.md](../notifications.md)）。ドロップで取り込んだ場合も同じ。
  画像以外のファイルをドロップした場合は注意トースト。

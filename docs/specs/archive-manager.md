# Archive Manager（アーカイブの一覧と出し入れ）

左端のマネージャーのグループの一番上「Archive Manager」（アイコン `inventory_2`。内部のモード名は `archive`）のメイン領域。
アーカイブはアプリの内部データで、ユーザーはフォルダを直接開かない。アプリへの出し入れ（バックアップ・別の PC への移行・取り込み）はここで、
成果物の画像の取り出しは Workspace の「画像の書き出し」（[flow-canvas.md](./flow-canvas.md)）で行う。保存形式と zip の形は [archives.md](./archives.md)。

## 画面
- AI パネル（右サイドバー）と左サイドバーは出さない（カテゴリーは持たない）。メイン領域に一覧を出す。
- 見出し「Archive Manager」と「<N> 件・<合計の容量>」、右に検索欄（「名前で検索」）、「インポート」、「エクスポート」、削除・元に戻す・更新のアイコン。
- 一覧は新しい順（更新日時。`GET /api/archives` と同じ順）。各行: チェック、サムネイル（最初の開始画像。なければ結果の最初の画像、画像がなければアイコン）、
  表示名、作成日時（`YYYY-MM-DD HH:MM`）、「画像 <N> 枚・結果 <N> 件」（Workspace に出る画像と結果フォルダの数）、容量（全ファイル）、「Workspace で開く」。
  - 見出し行のチェックで、表示中（検索で絞った後）の全行を選ぶ / 外す。選んでいる時は見出しの下に「<N> 件を選択中」。
  - サムネイルは行が画面に入った時に読み込む（Workspace と同じ 320px のサムネイル。起動中はメモリに持つ）。
- 検索は表示名の部分一致（大文字小文字を区別しない。空白で区切った語をすべて含むもの）。一致しない時は「「<語>」に一致するアーカイブはありません。」。
- アーカイブがない時は「アーカイブがありません。「インポート」で zip を読み込むか、Workspace で画像を読み込んでください。」。
- 開くたびに一覧を読み直す。表示中は、ほかの操作（ツールの結果の保存・削除・Undo・保存先の変更）でも読み直す。更新ボタンは完了トースト「最新の状態に更新しました」。
- チェックは読み直しても残す（消えたアーカイブのチェックだけ外す）。

## 開く
- 行のクリック（チェック・ボタン・名前の入力欄以外）と「Workspace で開く」で、Workspace に切り替えてそのアーカイブを表示する（選択はなし。表示したアーカイブは次の起動でも開く）。

## 名前の変更
- 行にマウスを載せると表示名の横に鉛筆（「名前を変更」）が出る。押すと入力欄になり、Enter・欄の外のクリックで確定、Esc で取り消し。
- 変えるのは表示名だけ（フォルダ名 = アーカイブの ID は変えない。[archives.md](./archives.md)「表示名」）。
- 前後の空白は除く。空・100 文字超・制御文字は注意トーストを出して入力を続ける。ほかのアーカイブと同じ名前はエラートースト
  「アーカイブの名前を変更できませんでした」（原文「同じ名前のアーカイブ「<名前>」があります。」）で元の名前に戻す。
- トースト「アーカイブの名前を「<名前>」に変更しました」。Workspace のドロップダウンも新しい名前になる。

## エクスポート
- チェックしたアーカイブ（一覧の順）を 1 つの zip にしてブラウザのダウンロードで保存する。チェックがない間は押せない。
  ファイル名は 1 件なら `confeito-archive-<表示名>-<YYYYMMDD_HHMMSS>.zip`、複数なら `confeito-archives-<YYYYMMDD_HHMMSS>.zip`
  （表示名のファイル名に使えない文字は `_`）。
- 書き出し中はボタンを「書き出し中…」にして押せなくする。トースト「アーカイブ <N> 件を <ファイル名> に書き出しました」。
  失敗はエラートースト「アーカイブを書き出せませんでした」。

## インポート
- 「インポート」でファイル選択（.zip、複数可）。一覧の上に zip ファイルをドロップしても同じ（ドロップ中は「zip ファイルをドロップしてアーカイブを読み込む」の枠）。
  zip 以外のファイルは注意トースト「zip ファイル以外は読み込めません」で外す。
- zip の中のアーカイブはすべて**新しいアーカイブとして追加**する。既存のアーカイブには触れない（同じ ID・表示名があれば `_2` / 「(2)」…）。
  読める zip と処理の規則は [archives.md](./archives.md)「エクスポート / インポート」。
- 読み込み中はボタンを「読み込み中…」にして押せなくする。トースト: 1 件「「<表示名>」を読み込みました」、複数「アーカイブ <N> 件を読み込みました」。
  外したファイル・読み込めなかったアーカイブは注意トースト（「読み込めなかったファイル <N> 件は外しました。」「「<名前>」を読み込めませんでした: …」）。
  zip として読めない・アーカイブがない zip はエラートースト「「<ファイル名>」をインポートできませんでした」。
- 読み込んだアーカイブは一覧の先頭に来る（読み込んだ日時が更新日時）。左端に線と「読み込み済み」の印を付ける（次のインポートまで）。検索欄は空にする。

## 削除と元に戻す
- 削除のアイコン（「チェックしたアーカイブを削除」。チェックがない間・削除や Undo の処理中は押せない）→ 確認「削除の確認」
  「アーカイブ「<名前>」を削除します（画像 <N> 枚）。」（複数は「アーカイブ <N> 件を削除します（画像 <N> 枚）。」）＋「Ctrl+Z で元に戻せます（アプリを終了するまで）。」。
- 削除はゴミ箱への移動で、Workspace の削除と同じ履歴に積む。元に戻すのアイコン・Ctrl+Z で戻せる（トースト・規則は [archives.md](./archives.md)「削除と Undo」）。

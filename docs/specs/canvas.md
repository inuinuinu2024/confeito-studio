# 比較キャンバス（Parallel / Overlay）

Workspace（モード名 `normal`）の処理フローは [flow-canvas.md](./flow-canvas.md)。ここは画像を比べる 2 つのモードの表示領域。

## 表示モード（左端のボタン、同時に 1 つ）
ボタンは上から Workspace、仕切り線、Parallel View、Overlay View（比較のモード）。もう一度押すと Workspace に戻る。
仕切り線の下のマネージャーのうち Prompt Manager と Character Manager も表示モードの 1 つ（サイドバーとメイン領域を使う。[prompt-manager.md](./prompt-manager.md)・[character-manager.md](./character-manager.md)）。
Batch モードはない（複数の画像への処理は Workspace で複数選択して実行する）。

## 比較する画像
- Workspace で選択している画像のうち、**選んだ順に最初の 2 枚**を比べる。
  Parallel は 1 枚目 = L（左）・2 枚目 = R（右）、Overlay は 1 枚目 = U（下絵）・2 枚目 = T（上絵）。
- モードを開始するたびに選択から取り直し、抜けると捨てる。比べる画像を変えるには Workspace に戻って選び直す。開始時・終了時は 100% を適用する。
- 画像を読み込めなかった時はエラートースト「「<ファイル名>」を読み込めませんでした」を出してその枠を空にする。
  ファイルがなくなった時（アーカイブが変わった通知の後の読み直しで見つからない）は、通知なしで空にする。
- 右サイドバー（AI パネル）は閉じて表示領域を広げる。ツールは実行しない。画像の D&D も取り込まず、注意トースト
  「<ボタン名（Parallel View / Overlay View）> では画像を取り込めません。Workspace に戻してからドロップしてください」を出す。
- 画像のない時の案内（アイコンと案内文。クリックの邪魔をしない）:
  | モード | 出す条件 | 案内文 |
  |---|---|---|
  | Parallel | L がない（左のペイン） | 左に表示する画像がありません。Workspace で比較する画像を選択（Ctrl+クリックで 2 枚目）してから切り替えてください |
  | Parallel | R がない（右のペイン） | 右に表示する画像がありません。2 枚選択すると 2 枚目を右に表示します |
  | Overlay | U も T もない | 重ね合わせる画像がありません。Workspace で比較する画像を選択（Ctrl+クリックで 2 枚目）してから切り替えてください |

## 背景色
- 画像の周囲（透明部分）は背景色で塗る。背景色は設定ウィンドウ（右上の歯車、Ctrl+B）の「背景色指定」ページ「キャンバスの背景色」で
  White / Light Gray / Dark Gray / Black / Checkerboard（既定）/ Blue / Green / Red から選ぶ。
  - 色を押すとすぐキャンバスに反映し、トースト「背景色を「<色名>」に変更しました」を出す。ウィンドウは閉じず、選択中の色に枠を付け、その下に「選択中: <色名>」を出す。
  - 選んだ色はその場でユーザー設定（`canvas_bgColor`）に保存し、次の起動でも使う（[app-shell.md](./app-shell.md)「設定の保存」）。
    保存がない時・一覧にない値の時は Checkerboard。

## ズームとスクロール
- 倍率は 10%〜1000%。100% は「表示領域（余白 64px を除く）にちょうど収まる大きさ」。
  Parallel の左右並べ表示では表示領域の半分（1 ペイン）が基準になる。
  要素の実サイズを変えて `overflow: auto` のネイティブスクロールで閲覧する（縦横比は px 指定で維持）。
- ズームバー: −/＋（10% 刻み）、スライダー、Fit to Screen（全体が見える最大倍率 = 100%。中央に表示）、
  Fit Width（幅を表示領域に合わせる。上限 100% なし、上端にスクロール）、Fit Height（高さを合わせる）。
  100% に戻すボタン（ホーム）は置かない（Fit to Screen が 100% と同じため）。
- Ctrl+ホイールでカーソル位置を中心に拡縮。
- ドラッグで表示位置を動かす（パン。画像データは変えない）。
  Parallel は左右の枠（ペイン）と境界線が固定で、中の画像が左右同じだけ動く（ズーム・ホイール・スクロールバーも同期）。
  Overlay で T を選択中のドラッグは T だけを動かす（下の Overlay モード）。
  - 画像が表示領域に収まっていても動かせる。画像の端が 64px は表示領域に残るところで止まる。
    ホイールスクロール・スクロールバーも同じ範囲で動く。
  - 位置は Fit to Screen / Fit Width / Fit Height で中央（または上端）に戻る。
    −/＋・スライダー・Ctrl+ホイールでは位置を保つ。表示領域の大きさが変わった時（ウィンドウ・サイドバーのリサイズ）も
    中央の点を保ったまま 100% の大きさを合わせ直す（Parallel の Slider の ON/OFF でペインの大きさが変わる時も同じ）。
- 2 枚が後から読み込まれて外接サイズが変われば 100% を適用し、変わらなければ倍率と位置を保つ。

## Parallel モード（左右に並べて比較。ボタン名「Parallel View」）
- L と R の画像を左右のペインに並べて表示する（上の「比較する画像」）。
- 表示領域を左右半分ずつの固定の枠（ペイン）に分け、間に 1px の半透明グレーの境界線を引く。
- 解像度の違う画像は実寸比のまま並べる。キャンバスは左右の画像の外接サイズで、各画像はその中央に置く
  （100% で外接サイズが 1 ペインに収まり、小さい画像はピクセル比どおり小さく見える）。
- 各ペインは自分の L / R だけを表示する（もう片方の画像で埋めない）。画像のないペインには、そのペインの中央に案内を出す。ズームバーは常に出す。
- 上部ツールバー: Slider（重ねて境界線をドラッグで比較）、Transpose（境界を水平方向に）、Flip（左右の入れ替え）。
  Transpose と Flip は Slider が ON の時だけ表示する。Parallel を抜けると Slider 系はすべて OFF、境界線の位置も中央に戻る。
- Slider: 2 つのペインを表示領域いっぱいに重ね、境界線より左（Transpose 時は上）に前面の画像を、反対側に背面の画像を見せる
  （前面は左の画像、Flip で右の画像）。
  - 境界線は画面に固定し、表示領域の端から端まで引く（画像を動かしても線は動かない）。1px の半透明グレーで、中央に小さな丸いつまみがある。
    線の両側 8px までつかめる。
  - 片方のペインが空の時の案内は、そのペインの見えている範囲の中央に出す。

## Overlay モード（下絵と上絵を重ねて比較。ボタン名「Overlay View」）
- 下絵（U）に単色ティントをかけ、その上に上絵（T）を半透明で重ねる。1 枚だけ選んでいればそれが U、T は空。
  色と不透明度はアプリを閉じるまで保つ（保存はしない）。
- U と T は中央を合わせて置く。キャンバスは U と T の外接サイズで、背景色はその全体に塗る。T を動かしてキャンバスの外へ出た部分は描かない。
- 上部ツールバー: Underdrawing (U) の色（青 `#448aff`・緑 `#4caf50`・赤 `#ff5252`・灰 `#9e9e9e`・なし、既定は青。
  選択中の色を再度押してもなし）、Top (T) の不透明度スライダー（既定 50%）、T の位置リセット（`restart_alt` アイコン）。
- T をダブルクリックで選択（青い破線枠。線幅は表示倍率によらず 2px）。選択中はドラッグまたは矢印キー（Shift で 10px）で移動できる。
  T の外をクリックすると選択解除。開始し直すと位置と選択は元に戻る。
- 矢印キーは T を選択中で、入力欄・テキストエリア・選択肢にフォーカスがない時だけ T の移動に使う（それ以外はスクロールなど通常の動き）。

# キャンバス（表示領域）

## 表示ルール
- 表示するのは ARCHIVES で選択中の画像だけ。何も選択していなければ何も表示しない。
  Normal モードで表示するのはファイルを 1 つだけ選んでいる時。フォルダを選んだ時・複数選択の時は何も表示しない（下の案内文）。
- ツールの対象画像（`DocumentManager` の画像）は、キャンバスに表示中の選択画像と常に同じ。テキストファイル・フォルダ・複数選択・
  選択なしの時は対象画像なし（背景除去・コマ分割は「未選択」、Nano Banana画像生成の原画も入らない）。
- 選択を素早く切り替えても、最後に選んだものだけを表示する（読み込みの終わる順に左右されない）。
  読み込めなかったファイルはエラートースト（[notifications.md](./notifications.md)）を出し、キャンバスを空にする。
- 何も表示していない時（起動直後・選択解除後など）は、キャンバス中央に案内を出す。アイコン、案内文、
  補足「または画像ファイルをここにドロップして読み込み」の 3 行。案内はクリック・ドロップの邪魔をしない。
  | モード | 出す条件 | 案内文 |
  |---|---|---|
  | Normal | 画像もテキストも表示していない | ARCHIVES から画像を選択してください |
  | Normal | フォルダを 1 つ選択 | フォルダ「<フォルダ名>」を選択中です。表示する画像を選択してください |
  | Normal | 複数選択 | <N> 件を選択中です。Normal モードでは 1 件ずつ表示します |
  | Compare | 左右どちらのペインにも何も表示していない | ARCHIVES から画像を選択してください |
  | Overlay | U も T もない | ARCHIVES から重ね合わせる画像（U: 下絵 / T: 上絵）を選択してください |
  | Batch | グリッドに出す画像が 1 枚もない | ARCHIVES から画像またはフォルダを選択してください |
- 選択を解除するとドキュメント画像もなくなるので、Compare の「選択のないペイン」や Overlay の U の代わりに前の画像を出すことはない。
- Normal モードではキャンバスの解像度を選択画像の実寸に合わせる（縦長・横長でも切れない）。
- 画像の周囲（透明部分）は背景色で塗る。背景色は View > Background Color（Ctrl+B）で
  White / Light Gray / Dark Gray / Black / Checkerboard（既定）/ Blue / Green / Red から選ぶ。
- 画像ファイルをキャンバスにドラッグ＆ドロップすると「画像読み込み」ツールと同じ処理で取り込む（通知も同じ。画像以外は注意トースト）。

## ズームとスクロール
- 倍率は 10%〜1000%。100% は「表示領域（余白 64px を除く）にちょうど収まる大きさ」。
  要素の実サイズを変えて `overflow: auto` のネイティブスクロールで閲覧する（縦横比は px 指定で維持）。
- 画像の読み込み時・ARCHIVES での選択時は 100% を適用し、横は中央、縦は表示領域に収まれば中央・はみ出せば上端を表示する。
- ズームバー: −/＋（10% 刻み）、スライダー、Fit to Screen（全体が見える最大倍率、上限 100%）、
  Fit Width（幅を表示領域に合わせる。上限 100% なし、上端にスクロール）、Fit Height（高さを合わせる）、ホーム（100%）。
- Ctrl+ホイールでカーソル位置を中心に拡縮。
- キャンバス上のドラッグで表示位置を動かす（パン。画像データは変えない）。全モード共通で、Compare は左右が一緒に動く。
  Overlay で T を選択中のドラッグは T だけを動かす（下の Overlay モード）。
  - 画像が表示領域に収まっていても動かせる。画像の端が 64px は表示領域に残るところで止まる。
    ホイールスクロール・スクロールバーも同じ範囲で動く。
  - 位置は ARCHIVES での選択時と Fit to Screen / Fit Width / Fit Height / ホームで中央（または上端）に戻る。
    −/＋・スライダー・Ctrl+ホイールでは位置を保つ。表示領域の大きさが変わった時（ウィンドウ・サイドバーのリサイズ）も
    中央の点を保ったまま 100% の大きさを合わせ直す。

## テキストファイルの表示
- ARCHIVES で json / txt / md を選ぶと、直前の画像のサイズに関係なく表示領域いっぱいにテキストを表示する。
- テキスト表示中はズームバーを隠し、画像を選び直すと戻る。
- テキスト上のドラッグは範囲選択・コピーとして働き、パンしない。
- 等幅フォント（Consolas 系）、行間 1.6、ダークテーマの枠と影付きコンテナ。

## 表示モード（左端のボタン、同時に 1 つ）
もう一度押すと Normal に戻る。
- Normal に戻った時は、その時の ARCHIVES の選択を Normal の規則で表示し直す（Batch 中に選び直した内容も反映する）。
  キャンバスの大きさは前のモード（Compare の外接サイズ・Batch のグリッド）を引き継がず、表示する画像の実寸に戻り、100% を適用する。

### Compare モード
- 右サイドバーが 2 つ目の ARCHIVES パネルになり、左右それぞれの選択を左右のペインに並べて表示する（開始時は左の選択を引き継ぐ）。
- キャンバスは表示中の画像すべての外接サイズになり、各画像は中央揃えで配置する。選択のないペインは現在のドキュメント画像を表示する。
- 上部ツールバー: Slider（重ねて境界線をドラッグで比較）、Transpose（境界を水平方向に）、Flip（左右の入れ替え）。
  Transpose と Flip は Slider が ON の時だけ表示する。Compare を抜けると Slider 系はすべて OFF に戻る。
- Compare 中は ARCHIVES の削除ボタンを無効にする。

### Overlay モード
- 下絵（U）に単色ティントをかけ、その上に上絵（T）を半透明で重ねる。
- U: ARCHIVES の画像行の右端に出るチェックボックス（列ヘッダー「U」付き）で選ぶ。モード開始時に U が未選択なら、
  選択中の画像を U にする。U がなく T もない場合は選択中の画像（なければドキュメント画像）を U として表示する。
- T: ARCHIVES で選択中の画像。
- 上部ツールバー: Underdrawing の色（青 `#448aff`・緑 `#4caf50`・赤 `#ff5252`・灰 `#9e9e9e`、既定は青。選択中の色を再度押すとティントなし）、
  Top の不透明度スライダー（既定 50%）、ホーム（T の位置をリセット）。
- T をダブルクリックで選択（青い破線枠）。選択中はドラッグまたは矢印キー（Shift で 10px）で移動できる。T の外をクリックすると選択解除。

### Batch モード
- ARCHIVES の選択に応じて、画像を 2 列のグリッド（1 タイル 800×600px）で表示する。
  - フォルダを 1 つ選択 → 配下（サブフォルダの中も含む）の全画像
  - ファイルを 1 つ選択 → その 1 枚だけのグリッド
  - 複数選択 → 選んだファイルだけ（選択に含まれるフォルダは無視）。並びはツリーの表示順（クリックした順ではない）
  - テキストファイル（json / txt / md）は表示しない。表示する画像が 1 枚もない選択では表示を変えない
- タイルにはファイル名と画像を描き、右半分は結果用の空き枠（市松模様）。ズームバーは隠す。

# キャンバス（表示領域）

## 表示ルール
- 表示するのは ARCHIVES で選択中の画像だけ。何も選択していなければ何も表示しない。
  Normal モードで表示するのはファイルを 1 つだけ選んでいる時。フォルダを選んだ時・複数選択の時は何も表示しない（下の案内文）。
- ツールの対象画像（`DocumentManager` の画像）は、キャンバスに表示中の選択画像と常に同じ。テキストファイル・フォルダ・複数選択・
  選択なしの時は対象画像なし（背景除去・コマ分割は「未選択」、Nano Banana画像生成の原画も入らない）。
- 選択を素早く切り替えても、最後に選んだものだけを表示する（読み込みの終わる順に左右されない）。
  読み込めなかったファイルはエラートースト（[notifications.md](./notifications.md)）を出し、キャンバスを空にする。
- 何も表示していない時（起動直後・選択解除後など）は、キャンバス中央に案内を出す。アイコン、案内文、
  補足「または画像ファイルをここにドロップして読み込み」の 3 行（Parallel / Overlay では取り込めないので補足は出さない）。案内はクリック・ドロップの邪魔をしない。
  | モード | 出す条件 | 案内文 |
  |---|---|---|
  | Normal | 画像もテキストも表示していない | ARCHIVES から画像を選択してください |
  | Normal | フォルダを 1 つ選択 | フォルダ「<フォルダ名>」を選択中です。表示する画像を選択してください |
  | Normal | 複数選択 | <N> 件を選択中です。Normal モードでは 1 件ずつ表示します |
  | Parallel | （全体の案内は出さず、ペインごとに出す。下の Parallel モード） | — |
  | Overlay | U も T もない | ARCHIVES の U / T 列で重ね合わせる画像（U: 下絵 / T: 上絵）を選択してください |
  | Batch | グリッドに出す画像が 1 枚もない | ARCHIVES から画像またはフォルダを選択してください |
- Parallel / Overlay は ARCHIVES の選択ではなく L / R・U / T のチェックで表示が決まる（選択・ドキュメント画像・もう片方の画像で埋めない）。
- Normal モードではキャンバスの解像度を選択画像の実寸に合わせる（縦長・横長でも切れない）。
- 画像の周囲（透明部分）は背景色で塗る。背景色は設定ウィンドウ（右上の歯車、Ctrl+B）の「表示」ページ「キャンバスの背景色」で
  White / Light Gray / Dark Gray / Black / Checkerboard（既定）/ Blue / Green / Red から選ぶ。
  - 色を押すとすぐキャンバスに反映し、トースト「背景色を「<色名>」に変更しました」を出す。ウィンドウは閉じず、選択中の色に枠を付け、その下に「選択中: <色名>」を出す。
  - 選んだ色はその場でユーザー設定（`canvas_bgColor`）に保存し、次の起動でも使う（[app-shell.md](./app-shell.md)「設定の保存」）。
    保存がない時・一覧にない値の時は Checkerboard。
- 画像ファイルをキャンバスにドラッグ＆ドロップすると「画像読み込み」ツールと同じ処理で取り込む（通知も同じ。画像以外は注意トースト）。
  Parallel / Overlay モード中は取り込まず、注意トースト「<ボタン名（Parallel View / Overlay View）> では画像を取り込めません。Normal モードに戻してからドロップしてください」を出す。

## ズームとスクロール
- 倍率は 10%〜1000%。100% は「表示領域（余白 64px を除く）にちょうど収まる大きさ」。
  Parallel の左右並べ表示では表示領域の半分（1 ペイン）が基準になる。
  要素の実サイズを変えて `overflow: auto` のネイティブスクロールで閲覧する（縦横比は px 指定で維持）。
- 画像の読み込み時・ARCHIVES での選択時は 100% を適用し、横は中央、縦は表示領域に収まれば中央・はみ出せば上端を表示する。
- ズームバー: −/＋（10% 刻み）、スライダー、Fit to Screen（全体が見える最大倍率 = 100%。中央に表示）、
  Fit Width（幅を表示領域に合わせる。上限 100% なし、上端にスクロール）、Fit Height（高さを合わせる）、ホーム（100%）。
- Ctrl+ホイールでカーソル位置を中心に拡縮。
- キャンバス上のドラッグで表示位置を動かす（パン。画像データは変えない）。全モード共通。
  Parallel は左右の枠（ペイン）と境界線が固定で、中の画像が左右同じだけ動く（ズーム・ホイール・スクロールバーも同期）。
  Overlay で T を選択中のドラッグは T だけを動かす（下の Overlay モード）。
  - 画像が表示領域に収まっていても動かせる。画像の端が 64px は表示領域に残るところで止まる。
    ホイールスクロール・スクロールバーも同じ範囲で動く。
  - 位置は ARCHIVES での選択時と Fit to Screen / Fit Width / Fit Height / ホームで中央（または上端）に戻る。
    −/＋・スライダー・Ctrl+ホイールでは位置を保つ。表示領域の大きさが変わった時（ウィンドウ・サイドバーのリサイズ）も
    中央の点を保ったまま 100% の大きさを合わせ直す（Parallel の Slider の ON/OFF でペインの大きさが変わる時も同じ）。

## テキストファイルの表示
- ARCHIVES で json / txt / md を選ぶと、直前の画像のサイズに関係なく表示領域いっぱいにテキストを表示する。
- テキスト表示中はズームバーを隠し、画像を選び直すと戻る。
- テキスト上のドラッグは範囲選択・コピーとして働き、パンしない。
- 等幅フォント（Consolas 系）、行間 1.6、ダークテーマの枠と影付きコンテナ。

## 表示モード（左端のボタン、同時に 1 つ）
ボタンは上から Normal Mode、Batch Mode、仕切り線、Parallel View、Overlay View（仕切り線の下は比較のモード）。もう一度押すと Normal に戻る。
- Normal に戻った時は、その時の ARCHIVES の選択を Normal の規則で表示し直す（Batch 中に選び直した内容も反映する）。
  キャンバスの大きさは前のモード（Parallel の外接サイズ・Batch のグリッド）を引き継がず、表示する画像の実寸に戻り、100% を適用する。

### チェック列（Parallel / Overlay 共通）
- 比較する画像は、ARCHIVES の画像行の右端に出る 2 つのチェック（四角）だけで選ぶ。列ヘッダーは Parallel が「L」「R」、Overlay が「U」「T」。
  - テキストファイル・フォルダの行にはチェックがない。もう一度押すと外れる。
  - ARCHIVES の行クリック（画像・テキスト・フォルダ・複数選択）は表示を変えない。選択はツリー上で変わり（保存先フォルダも従う）、
    モードを抜けた時に Normal の規則で表示する。
  - 開始するたびに選び直し、抜けると外れる（モードを切り替えても引き継がない）。開始時・終了時は 100% を適用する。
  - 2 つを替えた時は、外接サイズが変われば 100% を適用し、変わらなければ倍率と位置を保つ。
  - 画像を読み込めなかった時はエラートースト「「<ファイル名>」を読み込めませんでした」を出してチェックを外す。
    ARCHIVES の削除でファイルがなくなった時は、通知なしで外す。削除ボタンはこれらのモード中も使える。
- 右サイドバー（AI パネル）は閉じてキャンバスを広げる。ツールは実行しない（画像の D&D も取り込まない）。

### Parallel モード（左右に並べて比較。ボタン名「Parallel View」）
- L（左）と R（右）の画像を左右のペインに並べて表示する（上の「チェック列」）。開始時は L も R も空。
  同じ画像を L と R の両方にできる。
- 表示領域を左右半分ずつの固定の枠（ペイン）に分け、間に 1px の半透明グレーの境界線を引く。
- 解像度の違う画像は実寸比のまま並べる。キャンバスは左右の画像の外接サイズで、各画像はその中央に置く
  （100% で外接サイズが 1 ペインに収まり、小さい画像はピクセル比どおり小さく見える）。
- 各ペインは自分の L / R だけを表示する。画像のないペインには、そのペインの中央にアイコンと案内
  「ARCHIVES の L 列で左に表示する画像を選択してください」/「ARCHIVES の R 列で右に表示する画像を選択してください」を出す。
- テキストファイルは表示しない（チェックがない）。ズームバーは常に出す。
- 上部ツールバー: Slider（重ねて境界線をドラッグで比較）、Transpose（境界を水平方向に）、Flip（左右の入れ替え）。
  Transpose と Flip は Slider が ON の時だけ表示する。Parallel を抜けると Slider 系はすべて OFF、境界線の位置も中央に戻る。
- Slider: 2 つのペインを表示領域いっぱいに重ね、境界線より左（Transpose 時は上）に前面の画像を、反対側に背面の画像を見せる
  （前面は左の画像、Flip で右の画像）。
  - 境界線は画面に固定し、表示領域の端から端まで引く（画像を動かしても線は動かない）。1px の半透明グレーで、中央に小さな丸いつまみがある。
    線の両側 8px までつかめる。
  - 片方のペインが空の時の案内は、そのペインの見えている範囲の中央に出す。

### Overlay モード（下絵と上絵を重ねて比較。ボタン名「Overlay View」）
- 下絵（U）に単色ティントをかけ、その上に上絵（T）を半透明で重ねる。
- U と T は上の「チェック列」で選ぶ。同じ画像を U と T の両方にはできない（片方の列を付けると、もう片方の列のチェックは外れる）。
- 開始時は、画像ファイルを 1 つだけ選んでいればそれを U にし、T は空。色と不透明度はアプリを閉じるまで保つ（保存はしない）。
- U と T は中央を合わせて置く。キャンバスは U と T の外接サイズで、背景色はその全体に塗る。T を動かしてキャンバスの外へ出た部分は描かない。
- 上部ツールバー: Underdrawing (U) の色（青 `#448aff`・緑 `#4caf50`・赤 `#ff5252`・灰 `#9e9e9e`・なし、既定は青。
  選択中の色を再度押してもなし）、Top (T) の不透明度スライダー（既定 50%）、T の位置リセット（`restart_alt` アイコン。ズームバーのホームとは別）。
- T をダブルクリックで選択（青い破線枠。線幅は表示倍率によらず 2px）。選択中はドラッグまたは矢印キー（Shift で 10px）で移動できる。
  T の外をクリックすると選択解除。T を別の画像に替えると位置と選択は元に戻る。
- 矢印キーは T を選択中で、入力欄・テキストエリア・選択肢にフォーカスがない時だけ T の移動に使う（それ以外はスクロールなど通常の動き）。

### Batch モード
- 修正中。開くことはでき、開くたびに案内トースト「Batch モードは現在修正中です」を出す。
- ARCHIVES の選択に応じて、画像を 2 列のグリッド（1 タイル 800×600px）で表示する。
  - フォルダを 1 つ選択 → 配下（サブフォルダの中も含む）の全画像
  - ファイルを 1 つ選択 → その 1 枚だけのグリッド
  - 複数選択 → 選んだファイルだけ（選択に含まれるフォルダは無視）。並びはツリーの表示順（クリックした順ではない）
  - テキストファイル（json / txt / md）は表示しない。表示する画像が 1 枚もない選択では表示を変えない
- タイルにはファイル名と画像を描き、右半分は結果用の空き枠（市松模様）。ズームバーは隠す。
